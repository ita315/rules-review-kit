# ita-plugins

A Claude Code plugin marketplace.

| Plugin | Description |
|--------|-------------|
| [rules-review-kit](plugins/rules-review-kit/) | Review a change against a project's own rules, plus a Hebrew code explainer. |
| [file-viewer](plugins/file-viewer/) | A pane beside the chat with the project tree and a read-only file preview. |

## Install

```
/plugin marketplace add ita315/rules-review-kit
/plugin install rules-review-kit@ita-plugins
/plugin install file-viewer@ita-plugins
```
